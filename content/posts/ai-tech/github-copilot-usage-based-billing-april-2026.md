# GitHub Copilot 宣布 6 月起切换至基于使用量的计费模式

微软旗下代码托管平台 GitHub 通过官方博客宣布，其 AI 辅助编程工具 GitHub Copilot 将于 **2026 年 6 月 1 日**起正式切换至基于使用量的计费模式（usage-based billing），取代此前的定额+超额切换机制。

## 计费机制变化

在现行模式下，Copilot 各套餐用户如果使用额度耗尽，系统将自动切换至基于"Premium Requests"的计费方式。新的基于使用量计费模式将引入 **GitHub AI 积分（GitHub AI Credits）** 概念，每个套餐都将含有定额的 AI 积分，用户在使用过程中消耗积分。

值得注意的是，**代码补全（code completion）和下次编辑建议（next edit suggestion）功能不消耗 AI 积分**，这意味着基础的智能代码补全功能不受影响，主要影响的是更高级的 AI 对话、代码生成等重度使用场景。

## 价格保持不变

GitHub 明确表示，各套餐的基础价格维持不变：

| 套餐 | 价格 |
|------|------|
| Copilot 基础版 | 免费 |
| Pro | $10/月 |
| Pro+ | $39/月 |
| Business | $19/用户/月 |
| Enterprise | $39/用户/月 |

这一价格策略表明，GitHub 希望通过使用量计费更公平地分配资源，同时避免因重度用户消耗过多算力而导致服务体验下降的问题。

## 行业背景

GitHub Copilot 是全球最受欢迎的 AI 编程助手之一，拥有数百万开发者用户。此次计费模式的转变反映了 AI 工具行业的一个普遍趋势：随着大模型推理成本的持续高企，服务提供商正在从固定月费模式转向更精细化的使用量计费。

此前，多家 AI 服务提供商已陆续采用类似的积分制或用量制计费方案。分析人士认为，这一转变可能会引发连锁反应，推动整个 AI 开发者工具行业的计费模式演进。
