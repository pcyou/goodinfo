## Discord 大面积宕机

即时通讯平台 Discord 遭遇大规模服务中断，其 API 服务出现严重故障。大量用户报告无法正常访问服务器和发送消息。

Discord 方面已确认问题并正在进行修复。此次宕机影响了全球范围内的用户，许多依赖 Discord API 的第三方应用和机器人也受到波及。

这是 Discord 近期又一次较大规模的服务中断事件，引发了用户对其基础设施稳定性的讨论。
