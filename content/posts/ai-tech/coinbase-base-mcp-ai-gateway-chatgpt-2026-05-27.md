## [快讯] Base推出AI网关

Coinbase孵化的Base区块链正式推出MCP（Model Context Protocol）网关，将Base账户与ChatGPT、Claude和Cursor等AI客户端连接。

通过这一集成，用户可以使用自然语言提示进行代币兑换、转账及与Base上的DeFi应用交互。MCP是一种新兴标准，允许AI系统安全地访问外部工具和服务。

此举被视为加密行业与AI融合的重要一步，可能为普通用户使用DeFi降低门槛。

## Base Launches AI Gateway for ChatGPT and Claude

Coinbase's Base blockchain has rolled out an MCP (Model Context Protocol) gateway, connecting Base Accounts to AI clients like ChatGPT, Claude, and Cursor. Users can now use natural language prompts to swap tokens, transfer funds, and interact with DeFi apps on Base.
