## 🤖 AI 与科技

### 一、模型发布与头部公司动态

**1. OpenAI 全面开源 Codex Harness**  
OpenAI 将支撑 Codex CLI / IDE 插件的统一执行框架 Codex Harness 全部开源，包含工具调用循环、沙箱执行、子 Agent 编排等核心能力。这是 OpenAI 在 DevTools 栈层面少有的完整开源动作，对 Cursor、Aider、Claude Code 等竞品构成直接挑战。

**2. DeepSeek V4-Flash-Vision-Exp 上线**  
DeepSeek 在 Hugging Face 与 API 同步上线 V4-Flash-Vision-Exp 预览版本，正式开放图像理解与多模态 Agent 调用能力。社区基准显示其在长上下文 Agent 任务上表现接近 Anthropic Opus-4.8 水平，且定价仍维持 V4-Flash 系列的极低价位。

**3. Starcloud 融资 2.5 亿美元建设太空 AI 数据中心**  
由前 Google X 与 a16z 支持的 Starcloud 完成 2.5 亿美元 B 轮，估值 23 亿美元，将用于在低地球轨道部署搭载 Nvidia H100 / B200 的 AI 数据中心卫星。公司声称地面数据中心电源与冷却瓶颈使其转向太空算力。

**4. 谷歌 Gemma 系列下载破 10 亿次**  
Google 宣布 Gemma 系列开源模型累计下载量突破 10 亿次，社区已派生超过 10 万个微调与领域适配变体。Gemma 3 系列（1B/4B/12B/27B）成为端侧部署的事实标准之一。

**5. 马斯克：中国是 AI 领域最强竞争对手**  
马斯克在 X 平台公开表示，就 AI 技术发展而言，中国是迄今他所遇到的最强竞争对手。该言论与近期 xAI 频繁对比 DeepSeek、Qwen、Kimi 等中国模型的报道相呼应，反映中美 AI 竞速进入白热化阶段。

**6. 阿里云一次性接入 GLM-5.3 + DeepSeek-V4-Pro**  
阿里云通义千问平台一次性接入 GLM-5.3（智谱）、DeepSeek-V4-Pro 等国产主力模型，加上原有的 Qwen3-Max 与通义系列，构建国内最完整的 MaaS 矩阵。

**7. 商汤开源 SenseNova U1.5 Lite（8B 多模态原生 4K）**  
商汤科技发布并开源 SenseNova U1.5 Lite 多模态大模型，8B 参数规模，原生支持 4K 图像输出与中英双语对齐。

**8. 蚂蚁百灵开源 Ling-3.0 tiny/flash Base 模型**  
蚂蚁集团百灵大模型团队开源 Ling-3.0 tiny 与 flash 版本的 Base 模型权重，并首次公开训练过程中的关键 checkpoint，让研究者可以复现训练轨迹。

### 二、芯片、算力与基础设施

**9. Nvidia AVO 在 ARC-AGI-3 交互推理基准上取得 100% 得分**  
Nvidia 发布的研究显示，其 AVO（Agentic Visual Operator）模型在 François Chollet 主持的 ARC-AGI-3 交互推理基准测试中取得 100% 满分，是目前公开报道中首个达成此成绩的系统。

**11. 长江存储冲刺科创板 IPO，拟融资 330 亿元**

**12. 美光 CEO：AI 已彻底改变内存行业周期性格局**  
美光科技 CEO 表示，AI 训练与推理对 HBM 与高密度 DRAM 的需求已彻底打破过去 30 年内存行业的周期性规律，2026 年 HBM 产能将全年售罄。

**1. 30年期美债收益率飙至19年新高 5.27%**
