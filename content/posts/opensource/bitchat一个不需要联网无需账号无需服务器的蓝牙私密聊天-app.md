## 📰 正文

Bitchat 是一个完全脱离互联网、基于 蓝牙 Mesh 网络 的点对点加密通信应用，支持 iOS 与 macOS，专注隐私、安全与离线通信体验。


你打开 App，就能自动连接附近人，不论有没有信号都能发消息。还支持加频道、私聊、屏蔽人等功能。

- 

所有消息都经过端到端加密

- 

不用手机号、邮箱、注册

- 

没有服务器，信息存在你手机上，断电即消失

- 

支持紧急擦除，三击 logo 直接清空所有聊天

- 

还加入了“假动作消息”，防止流量分析



⚠️ 这可不是普通“加密聊天”，而是暗网级别隐私保护


它操作就像早期聊天室（IRC），你输入 /j #频道名 就能加入频道聊天。还有 /msg @人名 发私聊，甚至能设置频道密码、隐藏身份或一键清空所有聊天。

功能亮点



🔐 安全性与隐私保护


- 

端到端加密：私聊采用 X25519 + AES-256-GCM，群聊通过 Argon2id 派生密码进行加密

- 

数字签名：Ed25519 确保消息来源真实

- 

前向保密：每个会话使用新密钥

- 

匿名性：无需账号、手机号、注册信息

- 

紧急清除：三击 logo 即可清除所有数据



📡 Mesh 网络通信


- 

基于 蓝牙 BLE 的设备自动发现与连接

- 

多跳中继消息（支持 7 跳）

- 

消息缓存与“断网转发”支持离线用户

- 

使用 TTL 与唯一 ID 进行路由和去重



🧠 聊天功能


- 

支持 IRC 风格命令（如 /j, /msg, /who）

- 

支持频道创建与密码保护、转让、消息保留

- 

Mentions（@用户名）、自动补全

- 

消息压缩（LZ4），提高传输效率

- 

低功耗自适应，根据电量自动调整蓝牙活动频率



🎨 UI 与平台


- 

原生支持 iOS 与 macOS

- 

界面简洁，设有隐私优先机制

- 

Android 客户端尚未发布，但协议兼容，未来可构建

聊天指令示例：


- 

/j #channel 加入或创建频道

- 

/m @name hello 私聊

- 

/block @name 屏蔽用户

- 

/pass [密码] 设置频道密码

- 

/save 开启频道消息保存
