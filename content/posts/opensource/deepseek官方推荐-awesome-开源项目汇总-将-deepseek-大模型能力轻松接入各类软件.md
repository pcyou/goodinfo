## 📰 正文

Deepseek官方 GitHub 仓库 收集并整理了 DeepSeek AI 在各种应用和平台上的开源集成方案，提供了一系列可以直接使用或集成 DeepSeek AI API 的工具、插件和软件。


帮助你将 DeepSeek 大模型能力轻松接入各类软件。访问 DeepSeek 开放平台来获取您的 API key。


涵盖了 AI 聊天、编程、文档管理、翻译、语音交互等多个领域，帮助开发者和用户在不同场景下利用 DeepSeek AI 的能力。


适用于：


✅ 开发者（集成 DeepSeek API）


✅ 研究人员（使用 DeepSeek AI 进行文档分析）


✅ AI 工具爱好者（寻找 DeepSeek 支持的各种工具）


聊天应用


- 

Chatbox - 一个支持多种流行 LLM 模型的桌面客户端，可在 Windows、Mac 和 Linux 上使用。

- 

ChatGPT-Next-Web - 一键获取跨平台 ChatGPT 网页用户界面，支持流行的 LLM。

- 

留白记事 - 让你直接在微信上使用 DeepSeek 管理你的笔记、任务、日程和待办清单。

- 

Pal - AI Chat Client - 一款可以在 iPhone 或 iPad 上使用的 AI 助手。

- 

LibreChat - 可定制的开源应用程序，无缝集成 DeepSeek 以增强 AI 交互体验。

- 

PapersGPT - 集成 DeepSeek 及其他多种 AI 模型的辅助论文阅读 Zotero 插件。

- 

RSS翻译器 - 开源、简洁、可自部署的 RSS 翻译器。

- 

Enconvo - AI 时代的启动器，集 AI 功能入口与智能助理于一体。

- 

Cherry Studio - 为创造者而生的桌面版 AI 助手。

- 

ToMemo - 短语合集 + 剪切板历史 + 键盘输出的 iOS 应用，集成 AI 大模型。

- 

Video Subtitle Master - 批量为视频生成字幕并翻译，支持多种翻译服务。

- 

Easydict - 简洁易用的 macOS 词典翻译 App。

- 

Raycast - macOS 生产力工具，支持 DeepSeek AI。

- 

Nice Prompt - 结合提示工程与社交功能的平台。

- 

Zotero - 免费易用的文献管理工具。

- 

思源笔记 - 隐私优先的个人知识管理系统。

- 

go-stock - 由 LLM 提供支持的股票数据查看分析器。

- 

Wordware - 使任何人都可以通过自然语言构建、迭代和部署 AI 堆栈的工具包。

- 

Dify - 支持 DeepSeek 模型的 LLM 应用开发平台。

- 

LiberSonora - AI 赋能的开源有声书工具集。

- 

Bob - macOS 平台的翻译和 OCR 软件。

- 

STranslate - Windows 平台的翻译、OCR 工具。

- 

GPT AI Flow - 终极生产力武器，工程师的智能助手。

- 

Story-Flicks - 通过一句话生成高清故事短视频。



AI Agent 框架


- 

Anda - Rust 语言 AI 智能体框架。

- 

YoMo - 有状态无服务器 LLM 函数调用框架。

- 

Alice - 基于 ICP 的自主 AI 代理，支持 DeepSeek。



RAG 框架


- 

RAGFlow - 基于深度文档理解的开源 RAG 引擎。



Solana 框架


- 

Solana Agent Kit - 连接 AI 智能体到 Solana 协议的开源工具包。



即时通讯插件


- 

茴香豆 - 集成到个人微信群/飞书群的领域知识助手。

- 

LangBot - LLM 原生即时通信机器人平台。

- 

NoneBot - 适配 QQ/飞书/Discord/TG 等的 AI 机器人。



浏览器插件


- 

沉浸式翻译 - 双语对照网页翻译插件。

- 

沉浸式导读 - AI 网页摘要插件。

- 

ChatGPT Box - 将 LLM 作为私人助手整合到浏览器。

- 

划词翻译 - 多家翻译 API 及 LLM API 的浏览器插件。

- 

欧路翻译 - 提供鼠标划词搜索、逐段对照翻译等功能。

- 

流畅阅读 - 革新性的开源浏览器翻译插件。

- 

馆长 - 知识库 AI 问答助手。

- 

RssFlow - AI 驱动的 RSS 阅读器浏览器扩展。



VS Code 插件


- 

Continue - 开源 IDE 插件，AI 编程助手。

- 

Cline - AI 助手，可在 CLI 和编辑器中使用。



Neovim 插件


- 

avante.nvim - AI 驱动的 Neovim 编程助手。

- 

llm.nvim - 支持多种 LLM 的 Neovim 插件。

- 

codecompanion.nvim - AI 驱动的编码助手。



JetBrains 插件


- 

Chinese-English Translate - 中文翻译插件。

- 

AI Git Commit - 使用 AI 生成 Git 提交信息。



其它


- 

ShellOracle - 智能 shell 命令生成工具。

- 

深度求索（快捷指令） - 用 DeepSeek API 增强 Siri 能力。

- 

n8n-nodes-deepseek - n8n 社区节点，支持 DeepSeek API。

- 

promptfoo - 测试和评估 LLM 提示。

- 

deepseek-tokenizer - 高效轻量级 tokenization 库。

- 

deepseek-review - 代码审核工具，支持 GitHub Action。

- 

WordPress AI 助手 - DeepSeek API 的 WordPress AI 插件。
