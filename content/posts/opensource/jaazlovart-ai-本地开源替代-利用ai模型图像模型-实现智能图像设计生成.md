## 📰 正文

Jaaz 一个 Lovart.AI 的本地免费替代品。它允许用户设计、编辑和生成图像、海报、故事板等内容，并提供一个创意画布板，以便快速进行迭代和布局发布。


Jaaz 通过 AI模型+图像模型 实现智能设计生成，能够根据用户的指令自动生成创意内容，如图像、海报、故事板等。它可以批量生成多种设计元素，大幅提高了创作效率，适用于需要快速迭代设计的用户。

![image]()


Jaaz 允许用户在本地运行 AI 模型（如 Ollama），避免了依赖云服务的限制。这使得用户能够实现 本地生成图像 和内容，保护隐私并提高处理速度。它支持多种图像生成技术，如 Stable Diffusion 和 Flux Dev。

![image]()


主要功能



图像编辑与优化

- 

Jaaz 提供了强大的图像编辑功能，用户可以在聊天对话中编辑图像，包括：

- 

对象移除：删除图像中的不需要的元素。

- 

风格转移：改变图像的艺术风格。

- 

一致性角色生成：保持角色外观的一致性。

- 

局部元素调整：精准调整图像中特定部分。





![image]()



创意画布和故事板制作

- 

Jaaz 提供了一个 无限画布，支持自由创作和布局，用户可以在上面进行设计迭代和故事板的创作。这个画布没有任何限制，适合快速实现和修改创意构思。

![image]()



视频生成和编辑（即将推出）

- 

未来 Jaaz 将引入 视频生成功能，为用户提供视频生成和编辑工具，扩大其在多媒体创作领域的应用。通过 Wan2.1 和 Kling 等技术，用户将能够制作创意视频内容。



API 集成与多平台支持

- 

Jaaz 支持 多种 AI 模型的 API 集成（如 Claude、OpenAI 和 Gemini），用户可以通过 API 接口连接不同的语言模型，进行创作和设计。

- 

同时，支持通过 Replicate API 使用 多种图像生成模型，如 GPT-4O、Recraft、Flux 和 Google Imagen，提供灵活的创作方式。
