## 📰 正文

ComfyUI-Copilot 是一个由 阿里巴巴团队开发的 AI 智能助手节点插件，专为 ComfyUI 工作流程优化而设计。


它基于自然语言交互，提供 智能节点推荐、模型查询、工作流构建辅助与实时问答支持，大幅提升 Stable Diffusion 和多模态生成类项目的开发效率，降低使用门槛。


通俗易懂的理解就是：



它的目标是：用自然语言（说人话）来帮你搭建图像生成流程，让即使你不懂复杂的 AI 流程，也能轻松使用 ComfyUI 来生成编辑图像和视频等内容。


它就像 ChatGPT + SD + 节点图 的结合体，可以帮你自动：

- 

搭建节点流程图

- 

推荐合适的模型和节点

- 

解释每个节点是干什么的

- 

帮你诊断错误，修复问题

- 

用中文/英文回答问题，甚至推荐下载链接






📝 举个例子：生成一张森林中的梦幻女孩图


你只需输入：

> 

“我想生成一张SDXL风格的森林中的女孩图像，用LoRA模型，有雾气感。”



Copilot 会自动：
1. 

选择 SDXL 模型

2. 

插入相关 LoRA 节点

3. 

自动连接 Encode、Sampler、Output 等节点

4. 

优化提示词

5. 

搭建好整个流程



你几乎什么都不用动手，直接可以生成图像！





![image]()


它具体能干什么？



✅ 1. 会聊天的节点专家（智能问答机器人）



你可以直接对它说话，比如：


```None
objectivec复制“我要用SDXL生成一张森林里的女孩图像，推荐个流程”
“CLIPTextEncode这个节点是干嘛的？”
“我遇到报错了，帮我看看什么问题”

```



它就会：

- 

自动给你一个完整的流程图搭建出来

- 

解释每个节点的作用和参数怎么调

- 

如果报错了，它会给出解决建议



---



✅ 2. 自然语言生成工作流（你说它画）



直接用文字告诉它你想做什么，比如：

> 

“生成动漫风格的女孩照片，使用lora模型，高清，横图。”



它就会：

- 

推荐合适的模型（如 SDXL 或 anime 模型）

- 

自动搭建一个合理的流程图（图像生成流程）

- 

节点参数自动帮你填好



---



✅ 3. 模型查询 + 下载建议


- 

支持查询超过 60,000+ LoRA 与 Checkpoint 模型

- 

根据任务需求推荐合适的基础模型或微调模型



你可以问它：

- 

“有没有推荐的LoRA模型？”

- 

“哪里能下载 checkpoint？”



它会：

- 

查找你需要的模型

- 

提供 HuggingFace、CivitAI 的下载链接

- 

告诉你怎么用（接在哪个节点上）



---



✅ 4. 节点百科全书（Node 查询系统）



每个节点（像模块一样）都可以：

- 

查询它的功能解释

- 

参数是做什么用的

- 

常见错误和用法

- 

还能推荐它的“后续节点”（接下来该连什么）



---



✅ 5. 自动处理错误与建议



如果你遇到错误，它能：

- 

自动读取日志

- 

帮你分析哪一段出错

- 

给你中文/英文的修复建议



这对新手来说非常实用。


---



✅ 6. 子图推荐 + 提示词优化


- 

生成复杂流程时，它能推荐“子图”（某一步的小流程）

- 

自动优化你的提示词（Prompt），提升出图质量

- 

还能帮你分步骤构建长流程，比如“先生成草图，再上色”

🧰 怎么安装？（详细步骤）



🔸 方法一：用命令安装（适合有基础用户）



```None
cd ComfyUI/custom_nodes
git clone https://github.com/AIDC-AI/ComfyUI-Copilot.git

```



🔸 方法二：用 ComfyUI 自带的安装器（推荐）

1. 

打开 ComfyUI

![image]()

2. 

找到菜单里的 “Custom Nodes Manager”

![image]()

3. 

搜索 “ComfyUI-Copilot”

![image]()

4. 

点击安装按钮，一键搞定！



---



▶️ 启动使用


- 

安装好后，运行 ComfyUI

- 

页面右上角会出现一个 “Copilot” 按钮

- 

点它即可打开智能助手界面
