## 📰 正文

它是一个为中国开发者定制的 AI 编程工具包，让你用中文和 Claude AI 对话来写代码、优化架构、查资料。


为什么它特别？


- 

不需要翻墙，直接接入 Claude 的服务

- 

所有交互都支持中文，更适合国内开发者

- 

提供文档、咨询、音效、上下文管理等全套功能

🧩 功能详解



🗣️ 中文化支持（让 AI 会说“人话”）


- 

用中文直接对 Claude 说：请生成一个登录页面的 React 组件

- 

Claude 会理解并返回你想要的代码

- 

所有系统提示、错误信息、帮助文档都是中文



🧠 智能上下文管理（AI 不再“健忘”）


- 

每次对话，Claude 都会自动读取你的项目结构、文档内容

- 

不需要你每次都从头介绍项目背景，AI 更聪明，回答更准确

- 

跨会话记忆功能：你上次聊的内容，下次还能继续用



🚪 MCP 服务器支持（Claude 的“外挂工具”）



Claude 可以帮你做两件大事：


✅ Gemini 咨询系统（复杂问题咨询）

- 

你可以说：“Claude，请 Gemini 帮我分析这个代码的性能问题”

- 

适合解决复杂技术难题，比如：

- 

系统架构设计

- 

多文件重构

- 

性能优化建议




✅ Context7 文档系统（查文档神器）

- 

你可以说：“React 的最新 hooks 怎么用？”

- 

Claude 会：

- 

从官网查找最新文档

- 

提供代码示例

- 

告诉你哪些是新特性，哪些被废弃了




🛡️ 安全扫描（帮你保护隐私）


- 

每次和 Claude 交互之前，会自动扫描：

- 

API 密钥

- 

用户名/密码

- 

私有函数/配置文件


- 

避免把敏感信息传给 AI



🔔 提示音效 & 自动 Hook（让开发更“丝滑”）


- 

支持提示音：比如 Claude 回复你时会有“叮”的声音

- 

Hook 脚本：自动在项目启动、保存时执行操作（比如同步文档）



🚀 如何快速使用？



✅ 一键安装（推荐）



```None
curl -fsSL https://raw.githubusercontent.com/cfrs2005/claude-init/main/install.sh | bash

```



🛠️ 手动安装



```None
git clone https://github.com/cfrs2005/claude-init.git
cd claude-init
./setup.sh
```
