## Core Summary

Coinbase and Amazon Web Services (AWS) have announced a partnership allowing publishers using CloudFront and Web Application Firewall (WAF) to charge AI agents for content access via the x402 micropayment protocol. This marks a significant infrastructure development for the AI agent economy.

## Key Points

- Scope: AWS CloudFront and WAF users
- Protocol: x402 micropayment standard
- Use case: Automatic settlement when AI agents access paid content
- Significance: New revenue stream for publishers in the AI scraping era
