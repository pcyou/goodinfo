## [Brief] Firefox Launches Major Redesign with Rounded Tabs and Compact Mode

### Core Summary

Mozilla's Firefox browser has officially rolled out a new visual and functional redesign, featuring rounded tab design, a new theme system, and a Compact Mode targeted at power users.

### Event Details

According to The Verge, the latest Firefox update covers desktop versions across multiple operating systems. The most visible change is the tab appearance, with the overall style aligning more closely with the current design language of mainstream operating systems. The new theme system lets users pick from different color schemes and interface styles to suit their preferences, while Compact Mode is aimed at power users and offers higher information density and more flexible interface customization.
